# 📘 REVISE AI

REVISE AI is a smart study assistant built using Python and Streamlit that helps students generate concise summaries from study materials.

## 🚀 Features

- 📂 Upload PDF notes
- 📝 Automatic text extraction
- 📄 AI-based summary generation
- 🎯 Adjustable summary length
- 🌐 Deployed as a web application

## 🛠️ Technologies Used

- Python
- Streamlit
- PyPDF2
- Sumy
- NLTK

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
